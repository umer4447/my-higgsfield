# Darkroom

A rebuild of [higgsfield.ai](https://higgsfield.ai) — an AI-native creative
suite — done as the 8x assignment.

**Live:** _(see the links field)_ · **Teardown of the original:** [`recon/RECON.md`](recon/RECON.md)
· **Agent capture:** [`CAPTURE-TEST.md`](CAPTURE-TEST.md) · [`.agent-logs/`](.agent-logs/)

## The argument

Higgsfield has fourteen top-level surfaces — Image, Video, Audio, Genjutsu,
Effects, Cinema Studio, Marketing Studio, Supercomputer, 3D Jutsu, Layers, MCP,
Academy, Community, Contests. Most of them are the same generate loop wearing a
different hat. Meanwhile the loop itself has three holes in it:

1. **The feed hides its prompts.** You scroll a wall of beautiful output and
   learn nothing from any of it.
2. **Cost is invisible until it is spent.** Nothing tells you what a generation
   costs before you press the button. You reverse-engineer it from a footnote.
3. **Signed out, the composer is a black rectangle.** `/ai/image` renders
   nothing at all until you have an account.

Darkroom is the same product with those three things fixed and the other eleven
surfaces deleted.

| | Higgsfield | Darkroom |
|---|---|---|
| Surfaces | 14 | 4 |
| Prompt on a feed item | hidden | always, in full, with the template |
| Remix | — | one click, same model + preset + seed |
| Cost before you spend | no | itemised, on the button |
| Failed generation | you paid | automatic refund, in the ledger |
| Signed out | empty page | full composer, 40 credits |
| Generation blocks the page | yes | job tray, keep browsing |

## What it does

- **Compose** — one screen for stills and motion. Model, frame, batch size and
  preset are controls, not separate apps. `⌘↵` to develop.
- **The Wall** — the feed. Hover any frame to read its prompt; Remix loads the
  exact parameters into the composer.
- **Presets** — 18 prompt templates, each described in plain language, each
  showing the same test prompt rendered through it so you can compare like for
  like. Every template is readable in full.
- **Contact sheet** — your own work, searchable by prompt, publishable to the
  wall.
- **Ledger** — every credit debited and refunded, itemised.

## How generation works, honestly

Stills are real. They are generated by a keyless diffusion endpoint, chosen
deliberately: a live link handed to a stranger has to work without them holding
an API key, and without one key getting drained by whoever finds the URL.

Motion is a real job that produces a real generated keyframe, played under the
camera move the preset specifies. The frame is generated; the move is rendered
in the browser — which is also why **Export .webm** can hand you an actual video
file with no render farm behind it. The UI says this on every motion result
rather than implying a frame-by-frame video model is wired up. Wiring one is a
swap inside `src/lib/gen.ts`; nothing above it changes.

## What is deliberately left out

Audio, 3D, the canvas/layer editor, MCP and CLI, the ChatGPT plugin, Academy,
Contests, Community profiles, Enterprise, and both "Studios". Also real billing
and a server-side account system — plans switch locally so the demo keeps
working, and your library lives in your own browser.

Those are hours that went into the generate → job → library → remix loop
instead. That loop is the product; the other thirteen surfaces are a menu.

## Running it

```bash
npm install
npm run dev
```

Next.js 16 (App Router) · React 19 · Tailwind v4 · TypeScript. No database, no
environment variables, no API keys — it deploys as-is.

Fonts are self-hosted (`geist`, `@fontsource/instrument-serif`) rather than
fetched from Google at build time, so the build has no external dependency.

## Layout

```
src/lib/catalog.ts   models, presets, ratios, plans — all data, no JSX
src/lib/gen.ts       parameters -> a generated frame; the swap point for a real backend
src/lib/jobs.tsx     the job engine: debit, run off-screen, refund failures
src/lib/store.tsx    account, credits, library, ledger — shaped like a server would store it
src/lib/seed.ts      the wall's starting content, as real parameters rather than stock images
tools/               the capture hook, its backfill, and a Playwright screenshot script
recon/               the teardown of the original, with screenshots
.agent-logs/         every prompt and every response that built this
```
